## 📌 Description
Ridge and Lasso regression API predicting home valuations based on square footage, location index, and property age.

---

## 🛠️ Architecture & Highlights
- **Production Modular Design**: Standard clean code layout with runnable script entry point.
- **Extensible**: Ready for cloud deployment, Docker microservice wrapping, or educational analysis.

---

## 📦 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sparkx313/ml-house-price-prediction-service.git
   cd ml-house-price-prediction-service
   ```

2. **Run the entry point**:
   ```bash
   python price_predictor.py
   ```
